# 小学四则运算题目自动生成器 — 需求文档

## 1. 项目概述

实现一个命令行程序（或具有相似功能的图形界面程序），用于自动生成小学四则运算题目，并支持对答题结果的批改统计。

## 2. 术语与符号约定

### 2.1 数值定义

| 类型 | 定义 | 示例 |
|------|------|------|
| 自然数 | 0, 1, 2, … | `0`, `1`, `23` |
| 真分数 | 分子 < 分母的分数 | `1/2`, `2/3`, `5/8` |
| 带分数 | 整数部分 + 真分数，格式为 `整数'分子/分母` | `1'1/2`, `2'3/8` |

### 2.2 运算符与符号

- 运算符：`+`、`−`、`×`、`÷`
- 括号：`(`、`)`
- 等号：`=`
- 分隔符：空格（用于四则运算符和等号前后）

### 2.3 算术表达式文法

```
e = n | e1 + e2 | e1 − e2 | e1 × e2 | e1 ÷ e2 | (e)
```

其中 `e`、`e1`、`e2` 为表达式，`n` 为自然数或真分数。

### 2.4 四则运算题目

形如 `e =` 的表达式，其中 `e` 为算术表达式。

### 2.5 真分数输入输出格式

- 真分数五分之三表示为 `3/5`
- 真分数二又八分之三表示为 `2'3/8`

## 3. 功能需求

### 3.1 题目生成模式

#### 3.1.1 命令行参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| `-n <数量>` | 是 | 控制生成题目的个数，例如 `-n 10` 生成 10 道题 |
| `-r <范围>` | 是 | 控制题目中数值的范围，生成小于该值的运算题目，例如 `-r 10` 表示 10 以内（**不包括 10**） |

> **注意**：`-r` 参数必须给定，否则程序报错并给出帮助信息。该参数可设置为 1 或其他自然数。

#### 3.1.2 题目生成约束

生成的题目必须同时满足以下所有约束：

1. **无负数中间结果**：计算过程中不能产生负数。即算术表达式中如果存在形如 `e1 − e2` 的子表达式，那么必须满足 `e1 ≥ e2`。

2. **除法结果为真分数**：如果存在形如 `e1 ÷ e2` 的子表达式，那么其结果应是真分数（即不能整除为整数，也不允许假分数结果）。

3. **运算符数量限制**：每道题目中出现的运算符个数不超过 **3 个**。

4. **题目不重复**：程序一次运行生成的题目不能重复。判定重复的规则为：
   - 任何两道题目不能通过**有限次交换 `+` 和 `×` 左右两边的算术表达式**变换为同一道题目。
   - 示例：
     - `23 + 45 =` 和 `45 + 23 =` 是重复的题目。
     - `6 × 8 =` 和 `8 × 6 =` 是重复的题目。
     - `3+(2+1)` 和 `1+2+3` 是重复的题目（`+` 是左结合的，`1+2+3` 等价于 `(1+2)+3`，即 `3+(1+2)`，即 `3+(2+1)`）。
     - `1+2+3` 和 `3+2+1` **不重复**（前者等价于 `(1+2)+3`，后者等价于 `(3+2)+1`，无法通过有限次交换变成同一题目）。

#### 3.1.3 输出文件

##### Exercises.txt

生成的题目存入执行程序的当前目录下的 `Exercises.txt` 文件，格式如下：

```
四则运算题目1
四则运算题目2
……
```

每行一道题目，题目编号从 1 开始。

##### Answers.txt

在生成题目的同时，计算出所有题目的答案，并存入执行程序的当前目录下的 `Answers.txt` 文件，格式如下：

```
答案1
答案2
……
```

每行一个答案，与题目顺序一一对应。

**真分数运算示例**：`1/6 + 1/8 = 7/24`

#### 3.1.4 性能要求

程序应能支持 **一万道题目** 的生成。

#### 3.1.5 调用示例

```bash
Myapp.exe -n 10 -r 10
```

生成 10 道 10 以内的四则运算题目。

---

### 3.2 答案批改模式

#### 3.2.1 命令行参数

| 参数 | 说明 |
|------|------|
| `-e <exercisefile>.txt` | 题目文件路径 |
| `-a <answerfile>.txt` | 答案文件路径 |

#### 3.2.2 功能说明

程序应能支持对给定的题目文件和答案文件，判定答案中的对错并进行数量统计。

> **假设**：输入的题目都是按照顺序编号的符合规范的题目。

#### 3.2.3 输出文件

统计结果输出到当前目录下的 `Grade.txt` 文件，格式如下：

```
Correct: 5 (1, 3, 5, 7, 9)
Wrong: 5 (2, 4, 6, 8, 10)
```

说明：
- `:` 后面的数字表示对/错的题目的数量。
- 括号内的是对/错题目的编号，编号之间用 `, ` 分隔。

#### 3.2.4 调用示例

```bash
Myapp.exe -e Exercises.txt -a Answers.txt
```

## 4. 边界与异常处理

1. **缺少必填参数**：若未提供 `-r` 参数，程序应报错并给出帮助信息。
2. **参数合法性**：`-n` 和 `-r` 应为自然数；`-r` 至少为 1。
3. **文件不存在**：批改模式下若指定的文件不存在，应给出明确错误提示。
4. **题目格式异常**：批改模式下若题目/答案文件格式不符合规范，应给出明确错误提示（尽管题目假设输入规范，仍建议做基本校验）。

## 6. 验收测试用例

### 6.1 题目生成

```bash
Myapp.exe -n 10 -r 10
```

**预期**：
- 当前目录生成 `Exercises.txt` 和 `Answers.txt`。
- `Exercises.txt` 含 10 行题目，每行形如 `e = `。
- `Answers.txt` 含 10 行答案，与题目一一对应。
- 所有题目满足约束（无负数中间结果、除法结果为真分数、运算符 ≤ 3 个、题目不重复）。

### 6.2 缺少 -r 参数

```bash
Myapp.exe -n 10
```

**预期**：程序报错并给出帮助信息。

### 6.3 答案批改

```bash
Myapp.exe -e Exercises.txt -a Answers.txt
```

**预期**：
- 当前目录生成 `Grade.txt`。
- 格式为 `Correct: X (...)` 和 `Wrong: Y (...)`。

### 6.4 大规模生成

```bash
Myapp.exe -n 10000 -r 100
```

**预期**：成功生成 10000 道不重复的题目，程序在合理时间内完成。

## 7. 实现建议（非强制）

- 语言使用 Python。
- 建议将表达式建模为 AST（抽象语法树），便于：
  - 计算中间结果并校验约束。
  - 规范化表达式以判定重复（例如对 `+` 和 `×` 的操作数排序后比较结构）。
- 分数运算建议实现独立的 `Fraction` 类，支持约分、四则运算、与整数互转。
- 随机生成时采用「生成-校验-重试」策略，配合已生成题目集合去重。
