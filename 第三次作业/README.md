# 小学四则运算题目自动生成器

依据 [PRD.md](PRD.md) 实现的命令行程序，用于自动生成小学四则运算题目，并支持对答题结果进行批改统计。

## 环境要求

- Python 3.8 及以上（仅使用标准库，运行时无第三方依赖）
- 打包需要 PyInstaller，测试需要 pytest

## 安装依赖

```bash
pip install -r requirements.txt
```

## 目录结构

```
软件工程3/
├── src/
│   ├── main.py         # 程序入口，解析命令行参数，调度各模块
│   ├── fraction.py     # 分数类：约分、四则运算、格式化输出
│   ├── expression.py   # 表达式 AST：求值、约束校验、判重、解析与渲染
│   ├── generator.py    # 题目生成器：随机生成、去重
│   ├── grader.py       # 批改模块：解析题目与答案文件，比对统计
│   └── utils.py        # 通用工具：文件读写、参数校验、帮助信息
├── tests/              # pytest 单元测试
├── build.py            # 打包脚本（PyInstaller）
├── requirements.txt
├── Exercises.txt       # 运行时生成的题目文件
├── Answers.txt         # 运行时生成的答案文件
└── Grade.txt           # 批改模式下生成的统计结果文件
```

## 运行方式

源码方式运行：

```bash
python src/main.py -n 10 -r 10
```

打包后可执行程序方式运行（先执行 `python build.py`，产物为 `dist/Myapp.exe`）：

```bash
Myapp.exe -n 10 -r 10
```

## 参数说明

### 题目生成模式

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| `-n <数量>` | 是 | 生成题目的个数，例如 `-n 10` |
| `-r <范围>` | 是 | 操作数范围，生成小于该值的题目；`-r 10` 表示 10 以内（不含 10） |

缺少 `-r` 时程序报错并输出帮助信息。

### 答案批改模式

| 参数 | 说明 |
|------|------|
| `-e <题目文件>` | 题目文件路径，例如 `-e Exercises.txt` |
| `-a <答案文件>` | 答案文件路径，例如 `-a Answers.txt` |

## 使用示例

```bash
# 生成 10 道 10 以内的题目，输出 Exercises.txt 与 Answers.txt
python src/main.py -n 10 -r 10

# 生成 10000 道 100 以内的题目
python src/main.py -n 10000 -r 100

# 批改，输出 Grade.txt
python src/main.py -e Exercises.txt -a Answers.txt

# 缺少 -r 时给出帮助信息
python src/main.py -n 10
```

## 输出格式

- `Exercises.txt`：每行一道题目，形如 `1/6 + 1/8 = `
- `Answers.txt`：每行一个答案，与题目一一对应，形如 `7/24`
- `Grade.txt`：

```
Correct: 5 (1, 3, 5, 7, 9)
Wrong: 5 (2, 4, 6, 8, 10)
```

## 题目生成规则

1. 计算过程中不产生负数：任意 `e1 − e2` 均满足 `e1 ≥ e2`。
2. 任意 `e1 ÷ e2` 的结果为真分数（分子 < 分母）。
3. 每道题目的运算符个数不超过 3 个。
4. 题目不重复：仅按 `+`、`×` 的交换律判重（不按结合律）。
   - `23 + 45` 与 `45 + 23` 重复；`6 × 8` 与 `8 × 6` 重复。
   - `3 + (2 + 1)` 与 `1 + 2 + 3` 重复。
   - `1 + 2 + 3` 与 `3 + 2 + 1` 不重复。

## 打包

```bash
python build.py
```

生成的可执行文件位于 `dist/Myapp.exe`。

## 测试

```bash
pytest -q
```

## 说明与约定

- `-r` 仅约束题目中出现的操作数（自然数 `0..r-1`，真分数的分子与分母均 `< r`）；中间结果与最终答案可以大于等于 `r`。
- 输出中的运算符使用 `+ − × ÷`，解析时同时兼容 ASCII 的 `-`、`*`、`/`。
- 当数值范围过小（例如 `-r 1`）导致无法生成足够的不重复题目时，程序写入实际生成的题目并给出警告，退出码为 3。
